# Exercise illustrations

The exercise pictures in `core/ui/src/main/assets/exercises/` come from the Everkinetic open data
project by Greg Priday: https://github.com/everkinetic/data

They are licensed under Creative Commons Attribution-ShareAlike 4.0 International (CC BY-SA 4.0):
https://creativecommons.org/licenses/by-sa/4.0/

Changes were made: the pictures were converted to WebP, resized to 360 px and placed on a white
background; they are otherwise unchanged. The pictures stay under CC BY-SA 4.0 (share-alike applies
to the pictures only; the app code is unaffected).

Each picture has two frames: `<slug>-1.webp` (start) and `<slug>-2.webp` (end).
`mapping.json` maps a starter's English name to the slug; `unmatched.txt` lists the starters with no
picture (no Everkinetic exercise with the same movement and equipment).
